ClearBug Privacy Policy

Last updated: September 29, 2026

ClearBug is a Chrome extension that helps testers run test cases, record test steps and write bug reports. This policy explains what data ClearBug handles and where it goes.

What ClearBug records

Only while you are running a test case or have started recording, ClearBug records on the pages you test:

  • the actions you take (for example "Clicked button Submit" or "Entered ACME Ltd in Vendor name"),
  • errors produced by the page (JavaScript errors and failed network requests),
  • screenshots of the visible tab when you mark a step or report a bug.

Password fields and fields that look like card numbers, social security numbers, bank accounts or tokens are always masked. You can also choose to hide every typed value in Settings.

ClearBug also stores the test case files you import, your test results, and the bug reports you save.

Where the data is stored

All of this data is stored locally in your browser using Chrome's extension storage. It is not sent to the developer or to any server operated by the developer. ClearBug has no analytics or tracking.

Optional AI features

If you add your own Claude API key in Settings and click Write the report or Improve with AI, ClearBug sends the data needed for that request (your note, recorded steps, captured errors and, for bug reports, the screenshot) directly from your browser to Anthropic's API to generate the text. This only happens when you click one of those buttons. Anthropic's handling of API data is described in Anthropic's privacy policy. Your API key is stored locally in your browser.

Sharing

ClearBug does not sell or share your data. Data leaves your computer only when you export a file yourself or use the optional AI features described above.

Deleting your data

You can delete bug reports in the defect log and reset test results in the side panel. Removing the extension deletes all data it stored.
