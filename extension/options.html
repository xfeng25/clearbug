AI report writing

Website access

ClearBug needs access to the websites you test to record steps, catch page errors and take screenshots. It only records while you run a test case or start recording.

Privacy

Everything ClearBug records stays in your browser. Data only leaves your computer when you click Write the report with an API key set: your note, the steps, errors and screenshot are then sent to Anthropic's API to write that one report.
